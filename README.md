<summary><b>▶ &nbsp;how this page is built</b></summary>
<br/>

```text
hero / headers / nav / terminal / radar / waves / footer
  → hand-written animated SVG (SMIL) + ascii art, no JS, no images
typing text        → readme-typing-svg
stats / languages  → github-readme-stats
streak             → github-readme-streak-stats
summary cards      → github-profile-summary-cards
activity graph     → github-readme-activity-graph
contribution snake → Platane/snk (GitHub Action)

badges             → shields.io (dynamic json)
counter            → komarev
```
